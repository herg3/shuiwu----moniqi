# 个人所得税 · 界面模拟器

纯静态页面，双击 `index.html` 即可在浏览器打开，无需安装、无需构建、不联网。

## 文件

```
index.html      首页（可滚动：通知条→年度汇算→重点服务→4卡片→banner→新闻；卡片可横滑）
filter.html     收入纳税明细·查询条件页（选年度 / 选所得类型 / 查询）
income.html     收入纳税明细列表（按 ?year=&types= 取数，每条数值可点改）
message.html    消息
office.html     办&查
todo.html       待办
common.css      公共层（状态栏 / 导航栏 / tabbar / 字体）
assets/         从官方截图切出的素材
ref/个税/        你提供的原始截图（1179×2556 @3x，比对基准）
shots/          渲染截图与 diff 结果
tools/          开发期工具
```

## 页面链路

```
首页 4卡片「收入纳税明细」 → filter.html → (选年度/类型) → income.html?year=&types=
income.html「返回」        → filter.html
所有 tabbar 互相跳转（待办/我的页尚未做）
```

## 改数值

改动会写进 `localStorage`（键 `taxapp:db:<年份>`），刷新或切页回来都还在；
每个年份独立存储、互不影响。想恢复内置数据，清掉对应键即可。

打开 `income.html`，找到 `const DB = {`（按年份分库）里的对应年份：

```js
{ cat:'工资薪金', month:'2026-05', sub:'正常工资薪金',
  agent:'文昌市第二建筑安装工...', income:6000.00, tax:24.00 },
```

- 改这里 → 列表和顶部「收入合计 / 已申报税额合计」一起变
- 或者在页面上**直接点数字**改，失焦/回车落定，汇总实时重算；输入非法会回滚
- 增删条目：往数组里加/删一项即可，汇总自动求和

## 想继续加页面

每张截图对应一个页面。做法固定：

```bash
# 1. 从截图里量出几何（颜色、坐标、字号、行高）
# 2. 写成 HTML/CSS
# 3. 同参数渲染，和原图逐像素比
node tools/shot.js 新页面.html mine_new.png
python tools/compare.py <原图文件名.png> mine_new.png
```

`compare.py` 会输出平均通道差、完全一致像素占比、以及 32×32 的差异热区，
按热区坐标回去改对应元素，几轮就能收敛。截图参数必须是 393×852 逻辑像素
@DPR3，否则和原图对不上。

注意 `tools/shot.js` 会对 `body` 注入强制对齐样式（`.phone` 固定到 0,0），
因为 flex 居中在 3x 下会产生 0.5 物理像素偏移，导致所有边缘整圈报差异。
